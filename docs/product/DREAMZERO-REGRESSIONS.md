# DreamZero 실제 실행에서 발견한 회귀 수정

검증 대상: [World Action Models are Zero-shot Policies](https://arxiv.org/abs/2602.15922), 공식 [프로젝트](https://dreamzero0.github.io/)와 [코드](https://github.com/dreamzero0/dreamzero).

- 참고문헌에 `.ltx_bib_title`이 없는 LaTeXML 문서에서는 저자·제목·학회가 합쳐져 제목 일치 검색이 실패했다. 별도 `.ltx_bibblock`의 제목을 사용하고, 과거 수집 기록은 캐시된 원문에서 다시 추출한다. 외부 논문의 제목 일치와 원문 인용 근거는 유지한다.
- 한국어에 LaTeX 문자열이 노출됐다. 검증한 수식 placeholder를 `ko_template`에 보존하고 화면에서는 정제된 원문 MathML을 복제한다. 생성된 한국어와 수식은 사용자 원문 주석의 좌표 계산에서 제외한다.
- 모델이 출력한 이중 이스케이프 줄바꿈은 수식 치환 전에 제한적으로 정규화한다.
- 짧은 문단이 많은 문서에서 요청 횟수가 과도했다. 배치당 최대 24블록, 원문 12,000자 기준으로 묶고 번역 작업만 low reasoning을 사용한다. 논문 분석의 설정은 유지한다. 원문 인용·ID·수식 토큰의 결정적 검증을 거친 결과만 저장한다.
- 개념 연결용 사용자 하이라이트와 자동 분류가 겹치면서 색이 혼합됐다. 자동 분류에 우선순위와 밝은/어두운 테마별 불투명 배경을 지정한다. 분류를 끄면 사용자 하이라이트를 확인할 수 있다.
- 재시도 과정의 번역 작업 로그가 논문 분석 진행 표시를 가렸다. 논문 진행 표시에서 reader/knowledge 보조 작업을 제외한다.

회귀 테스트: 구조화된 참고문헌 제목 추출, 수식 토큰 보존, 한국어 MathML 표시, 수식 앞뒤 원문 UTF-16 위치, 기존 번역 재사용, 원문/지침 변경 무효화. 개인 라이브러리나 번역 전문은 저장소에 포함하지 않는다.
