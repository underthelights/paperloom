# 논문별 연산 해설

참고: [Nathan Yan의 π0.7 구현 해설 영상](https://x.com/OfficialNathanY/status/2111446728608280760), 2026-10-18 확인. 영상에서 관찰한 목차·설명·연산 시각화의 구성만 참고한다. 영상의 모델 수치·아키텍처를 다른 논문에 재사용하지 않는다.

- 논문 화면의 `연산 해설`: 단계 목차, 읽기 진행률, 입력→연산→출력, 관계식, 학습/추론 표시, 원문·고정 커밋 코드, 개념 노트 연결.
- 새 분석의 `walkthrough`는 실제 근거에서 작성한다. shape·조건을 확인하지 못하면 `확인 불가`로 남긴다. 빈 보고서에는 일반 Transformer 설명을 해당 논문의 구현인 것처럼 채우지 않는다.
- 공개 정적 사례는 DreamZero(2602.15922) 13단계이며 다른 arXiv ID에 사용하지 않는다. 사용자의 새 보고서에 walkthrough가 있으면 그 결과를 우선한다.
- DreamZero 13단계에는 31개 세부 설명을 연결한다. 축별 index 식, stride와 contiguity, broadcast, attention의 축약 축, mask, loss 평균, gradient 경계를 코드 사실·수학적 유도·교육 예시·확인 불가로 구분한다.
- Attention 교육 예제는 작은 Q/K/V의 내적, √d 스케일링, 행별 softmax, V 가중합을 실제 계산한다.
- 수치 조작 시각화는 별도 교육용 예제이다. 실제 weight, activation, 모델 실행, 실험 재현을 주장하지 않는다.
- 현재 탐색은 목차와 이전·다음 버튼이다. 영상의 전체 스크롤 연출이나 모든 모델별 실측 텐서 재생을 구현했다고 주장하지 않는다.

검증: Python walkthrough 정규화 테스트, 브라우저 탐색·shape·출처·예시 수치·개념 이동·모바일 및 다크 테마 테스트. 실제 GPU 모델 forward는 실행하지 않는다.
