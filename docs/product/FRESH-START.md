# 새 라이브러리 운영 원칙

2026-10-18 사용자 요청: 이전 후보와 자료를 기본 라이브러리에서 분리하고 새로 시작한다.

- 후보 탭과 후보 수를 제거한다. 예전 Notion 후보는 앞으로 읽어야 할 할 일 목록으로 취급하지 않는다.
- 사이드바에는 최근 변경한 논문 최대 5개만 표시한다. 나머지는 검색·분류·개념·연도 필터를 제공하는 서가에서 찾는다.
- 검색 결과가 5개보다 많으면 `서가 전체 보기`가 검색어를 전달한다. 전체 논문은 페이지 단위로 탐색한다.
- 이번 개인 데이터 초기화는 기존 research 디렉터리를 별도 보관하고 빈 디렉터리로 시작한다. 브리프·노트·원문·주석을 삭제하지 않는다. 보관 위치와 DB 무결성 검사를 maintenance 기록에 남긴다.
- 공개 빌드의 seed는 비어 있어야 한다. 이전 Notion 후보를 자동 재주입하지 않는다.
- 보관 자료는 현재 서가·추천·개념 지도에 섞이지 않는다. 필요할 때 별도 보관본에서 선택적으로 가져온다. 보관본을 앱에서 선택 복원하는 UI는 아직 없다.
- 장기적으로 저장 검색·읽기 상태·즐겨찾기를 도입한다. 현재 최근 작업은 열람 시각이 아니라 자료의 변경 시각 기준이다.
