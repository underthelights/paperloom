# Current limitations

- Full original-source analysis currently targets arXiv; DOI/OpenAlex imports can remain metadata-only.
- Citation graphs use a bounded public-index sample, not Connected Papers' proprietary algorithm.
- Concept analysis uses up to 12 linked papers with truncated source context. Different concept names are not semantically merged automatically.
- Manim supports two educational templates, not arbitrary automatic lecture production. No narration or YouTube upload.
- Author profiles require primary-source identity confirmation; unknown degrees, affiliations, and LinkedIn URLs remain unknown.
- No iPad cloud synchronization, handwriting, notarization, automatic application updates, or validated Windows release.
